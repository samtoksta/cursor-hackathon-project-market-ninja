# Setup Instructions

## Convex Setup

1. Run Convex dev to initialize your project:
   ```bash
   npx convex dev
   ```

2. Follow the prompts to:
   - Authenticate (if not already done)
   - Create a new project or select an existing one

3. This will automatically create a `.env.local` file with your `NEXT_PUBLIC_CONVEX_URL`

## Running the App

Once Convex is set up, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see your app.

## Project Structure

- `app/` - Next.js app directory with pages and components
- `convex/` - Convex backend functions and schema
- `app/ConvexClientProvider.tsx` - Convex React client provider

## Next Steps

Your basic app is ready with:
- ✅ Next.js with TypeScript
- ✅ Tailwind CSS for styling
- ✅ Convex integration (needs initialization)
- ✅ Simple URL input interface
